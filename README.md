# 도장판 — 설치 및 연동 안내

웹과 휴대폰에서 같은 기록을 쓰기 위한 설정 안내입니다.
순서대로 따라 하면 되고, **1단계까지만 해도 폰에서 앱처럼 쓸 수 있습니다.**

## 폴더에 든 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 본체 (Firebase 설정을 여기에 넣습니다) |
| `manifest.webmanifest` | 홈 화면에 추가될 때 쓰는 앱 정보 |
| `sw.js` | 오프라인에서도 앱이 열리게 하는 서비스워커 |
| `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` | 앱 아이콘 |
| `firestore.rules` | 데이터베이스 보안 규칙 (2단계에서 붙여넣기) |

---

## 1단계 — 인터넷에 올리기 (약 15분)

파일을 올려두면 폰에서도 주소로 접속할 수 있습니다. 무료입니다.

### Vercel로 올리는 법 (가장 간단)

1. [vercel.com](https://vercel.com) 가입 (깃허브 계정 없이 이메일로도 가능)
2. 상단 **Add New → Project → Deploy** 화면에서, 이 폴더를 **통째로 드래그해서 업로드**
3. 잠시 뒤 `https://무언가.vercel.app` 주소가 나옵니다

> 파일을 수정할 때마다 같은 자리에 다시 드래그하면 갱신됩니다.
> 나중에 깃허브에 올려두면 자동 배포도 됩니다.

### 폰에 설치

- **아이폰(사파리)** — 주소 접속 → 하단 공유 버튼 → **홈 화면에 추가**
- **안드로이드(크롬)** — 주소 접속 → 우측 상단 ⋮ → **앱 설치** 또는 **홈 화면에 추가**

주소창 없이 전체화면으로 뜨고, 아이콘도 생깁니다. 앱스토어 등록은 필요 없습니다.

**여기까지 하면** 폰과 PC 각각에서 앱처럼 쓸 수 있지만, 기록은 기기마다 따로 저장됩니다.
기기를 오갈 필요가 없다면 여기서 멈춰도 됩니다. (백업은 앱 안의 **기록 내보내기**로)

## 2단계 — Firebase 연동 (약 30분, 기록이 기기끼리 이어집니다)

### 2-1. 프로젝트 만들기

1. [console.firebase.google.com](https://console.firebase.google.com) 접속 → **프로젝트 추가**
2. 이름은 아무거나 (예: `dojangpan`)
3. **Google 애널리틱스는 사용 안 함**으로 두면 설정이 간단합니다

### 2-2. 로그인 방식 켜기

1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **Sign-in method** 탭 → **Google** 선택 → 사용 설정 → 지원 이메일 고르고 저장
3. **Settings → 승인된 도메인**에 1단계에서 받은 주소(`무언가.vercel.app`)를 추가

> 이 도메인 추가를 빠뜨리면 로그인 팝업이 열리자마자 닫힙니다. 가장 흔한 실수입니다.

### 2-3. 데이터베이스 만들기

1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치는 `asia-northeast3 (서울)` 권장
3. **프로덕션 모드**로 시작
4. 만들어진 뒤 **규칙** 탭으로 가서, 내용을 지우고 `firestore.rules` 파일 내용을 붙여넣고 **게시**

이 규칙이 "각자 자기 기록만 읽고 쓸 수 있다"를 보장합니다.

### 2-4. 설정값 복사해 넣기

1. 왼쪽 위 톱니바퀴 → **프로젝트 설정**
2. 아래로 내려 **내 앱 → 웹(`</>`)** 아이콘 클릭, 앱 닉네임 아무거나 입력해 등록
3. 화면에 나오는 `firebaseConfig` 값을 `index.html` 위쪽에 그대로 옮겨 적습니다

```js
const FIREBASE_CONFIG={
  apiKey:"AIzaSy...",              // 그대로 복사
  authDomain:"dojangpan.firebaseapp.com",
  projectId:"dojangpan",
  appId:"1:123...:web:abc..."
};
```

> 이 값들은 공개되어도 괜찮습니다. 실제 보안은 2-3의 규칙이 담당합니다.

4. 수정한 `index.html`을 다시 배포(드래그 업로드)

### 2-5. 확인

1. PC에서 접속 → **목표 관리** 탭 상단에 **구글로 로그인** 버튼이 보이면 성공
2. 로그인 → 기존에 이 기기에 남아 있던 기록이 있으면 "클라우드로 올릴까요?"라고 물어봅니다
3. 폰에서 같은 주소 접속 → 같은 계정으로 로그인 → 목표가 그대로 보이면 완료

## 알아두면 좋은 것

**오프라인에서도 도장이 찍힙니다.** 지하철에서 체크해도 화면에 바로 반영되고, 인터넷이 연결되면 자동으로 올라갑니다. 목표 관리 상단의 점 색으로 상태를 볼 수 있어요 (초록 = 동기화 중, 주황 = 오프라인).

**두 기기에서 같은 날 찍어도 안전합니다.** 도장을 한 칸씩 따로 저장하기 때문에 서로 덮어쓰지 않습니다.

**비용은 사실상 0원입니다.** Firebase 무료 한도는 하루 읽기 5만 회인데, 이 앱은 하루 수십 회 수준입니다.

**앱을 고친 뒤 폰에서 옛 화면이 보인다면** `sw.js` 첫 줄의 `dojangpan-v1`을 `v2`로 바꿔 다시 배포하세요. 서비스워커가 예전 파일을 캐시하고 있어서 그렇습니다.

**기록 백업**은 Firebase를 붙인 뒤에도 가끔 해두시길 권합니다. 목표 관리 하단의 **기록 내보내기** → 파일로 저장.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 로그인 팝업이 바로 닫힘 | 2-2의 **승인된 도메인**에 배포 주소가 없습니다 |
| "이 기기에만 저장 중" 문구가 계속 보임 | `FIREBASE_CONFIG`가 비어 있거나 오타. 브라우저 콘솔(F12)에 오류가 찍힙니다 |
| `Missing or insufficient permissions` | 2-3의 규칙을 게시하지 않았습니다 |
| 홈 화면 추가가 안 보임 | `https` 주소여야 합니다. `file://`로 연 파일은 설치되지 않습니다 |
